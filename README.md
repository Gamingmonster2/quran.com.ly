# القرآن الكريم بالرسم العثماني — quran.com.ly

![القرآن الكريم بالرسم العثماني](public/og-image.png)

مصحف إلكتروني وقاعدة بيانات مفتوحة المصدر للقرآن الكريم بالرسم العثماني، منشور على **[quran.com.ly](https://quran.com.ly/)**.

## الشكر والفضل

بدأ المشروع بفكرة وهيكل مبدئي بسيط، وبمساعدة أدوات **Google AI Studio** في جلب بيانات القرآن الكريم بصيغة JSON فقط. بعد ذلك أُكمل تطوير المشروع وتخصيصه وتوسيعه وصيانته بالكامل من صاحب المشروع: واجهات القراءة، والتلاوات الصوتية بعدة قرّاء، والسمات، والبحث، والعلامات المحفوظة، والبيانات الوصفية للسيو، وغيرها. الإشارة إلى أدوات جوجل هنا هي شكر على المساعدة الأولية في جلب الملفات، ولا تعني ملكيتها للمشروع أو استمرار اعتماد المشروع عليها.

## المزايا

- **نص القرآن كاملًا**: ٦٢٣٦ آية بالرسم العثماني موزّعة على ١١٤ سورة، بصيغة JSON.
- **تلاوات صوتية آية بآية**: ١٥ قارئًا (العفاسي، الحصري، المنشاوي، عبد الباسط، السديس، الشاطري، الحذيفي، المعيقلي، محمد أيوب، العجمي، جبريل، الشريم، بصفر، الرفاعي…)، مع تتبّع الآية آية بآية وزرّي التالي/السابق وتكرار الآية.
- **فهرس السور**: بحث بالاسم أو الرقم، وتصفية مكية/مدنية.
- **وضعان للقراءة**: آية بآية، وقراءة متصلة على شكل المصحف.
- **بحث فوري** في جميع الآيات مع تجاوز التشكيل، وفهرس بحث مبني في المتصفح.
- **ترجمة إنجليزية** (Saheeh International) قابلة للإظهار/الإخفاء لكل آية.
- **التفسير الميسر** في لوحة قابلة للطي لكل آية.
- **ترجمة كلمة بكلمة** مع النقل الصوتي لكل كلمة.
- **علامات مرجعية** محفوظة في المتصفح.
- **السمات**: وضع ليلي (افتراضي) ووضع بيج مريح للعين، مع حفظ الاختيار.
- **الخطوط**: تضمين خطوط مجمع الملك فهد لطباعة المصحف الشريف (TTF) مع مبدّل خطوط وتحكّم بحجم الخط.
- **مستودع البيانات**: معاينة JSON، وهيكليته، وأكواد استخدام (JavaScript/Python/cURL/CSS/Flutter/React Native)، وتنزيل `quran.json` و`quran-by-surah.json`.
- **تحسين محركات البحث**: وصف ونطاق وبيانات منظّمة JSON-LD، وصورة مشاركة، و`sitemap.xml` و`robots.txt` و`site.webmanifest` وأيقونة الموقع، و**تصيير مسبق ثابت** لكل سورة وصفحات الموقع (HTML قابل للأرشفة حتى بدون JavaScript).
- **تطبيق ويب تقدمي (PWA)**: عامل خدمة (Service Worker) يُولَّد تلقائيًا بعد البناء، وتخزين مؤقت للغلاف والبيانات والخطوط — الموقع يعمل جزئيًا **دون اتصال** بعد أول زيارة.
- **واجهة بيانات موثّقة (Content API)**: كل البيانات كملفات JSON ثابتة مع CORS مفتوح وتوثيق في [docs/API.md](docs/API.md) وصفحة `/api`.

## التقنيات

React 19 · TypeScript · Vite · Tailwind CSS 4 · lucide-react

## التشغيل محليًا

```bash
npm install
npm run dev        # خادم التطوير على http://localhost:3000
npm run build      # بناء الإنتاج إلى مجلد dist (يولّد خرائط الموقع تلقائيًا)
npm run preview    # معاينة نسخة الإنتاج
npm run lint       # فحص الأنواع (tsc)
npm run sitemap    # توليد خرائط الموقع المقسّمة يدويًا
npm run content:translations   # تجديد ترجمة Saheeh International
npm run content:tafsir         # تجديد التفسير الميسر
npm run content:words          # تجديد بيانات كلمة-بكلمة
```

## مصادر البيانات والتلاوات

- **نص القرآن**: بيانات مشروع [quran-json](https://github.com/risan/quran-json) المفتوح المصدر (الرسم العثماني، ٦٢٣٦ آية).
- **التلاوات الصوتية**: تلاوات آية بآية من [شبكة islamic.network](https://islamic.network/) لخمسة عشر قارئًا.
- **الترجمة الإنجليزية**: ترجمة [Saheeh International](https://quran.com) عبر [Quran.com API v4](https://api.quran.com/) (مضمّنة محليًا لكل سورة).
- **التفسير الميسر**: [التفسير الميسر](https://quran.com) عبر Quran.com API v4 (مضمّن محليًا لكل سورة).
- **كلمة بكلمة**: بيانات الكلمات والمعاني الإنجليزية والنقل الصوتي من Quran.com API v4 (مضمّنة محليًا لكل سورة).
- **الخطوط**: خطوط مجمع الملك فهد لطباعة المصحف الشريف، وخطوط Amiri / Amiri Quran و Plus Jakarta Sans، وجميعها **مضمّنة محلياً** داخل المشروع (رخصة SIL Open Font License) دون الاعتماد على أي خدمة خطوط خارجية.

> يُرجى مراعاة حقوق الناشرين الأصليين للترجمة والتفسير عند إعادة استخدام هذه البيانات خارج هذا المشروع.

## الواجهة البرمجية (API)

جميع بيانات الموقع متاحة كملفات JSON ثابتة (نص القرآن، الترجمة، التفسير، كلمة بكلمة) مع رؤوس CORS مفتوحة عبر `public/_headers`، وتوثيق كامل في [docs/API.md](docs/API.md) وصفحة تفاعلية على المسار `/api`.

## النشر

الموقع منشور عبر **Cloudflare Pages**:

- أمر البناء: `npm run build`
- مجلد الإخراج: `dist`
- إصدار Node: محدّد في `.node-version`
- إعادة توجيه المسارات إلى `index.html` عبر `public/_redirects` (والصفحات المسبقة تُخدم عبر Pretty URLs)\n- بعد البناء: توليد خرائط الموقع (prebuild)، ثم تصيير السور/الصفحات الثابتة وتوليد عامل الخدمة (postbuild) تلقائيًا
