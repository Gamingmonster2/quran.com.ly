## مبادئ «اللمسة الخاصة بنا» (تسري على كل خطوة)

1. **عربي أولًا وبأصالة**: خطوط KFGQPC، زخرفة إسلامية خفيفة من تصميمنا، ألوان stone/emerald هادئة.
2. **أوفلاين أولًا ومجاني بالكامل**: كل ما يمكن تنفيذه في المتصفح (بطاقات/فيديو/حفظ) بلا سيرفر وبلا حساب إلزامي.
3. **خصوصية**: لا كوكيز تتبّع، والبيانات محلية افتراضيًا، والحساب اختياري للمزامنة فقط.
4. **سرعة وثبات**: صفحات ثابتة مصيَّرة مسبقًا + PWA + فحص آلي قبل كل نشر.
5. **تجربة هادئة**: «وضع تركيز»، آية اليوم/تدبّر، بلا مشتتات — بدل صفحات مزدحمة.
6. **محتوى منسّق بعناية**: قوائم مختارة (آية اليوم/الأسبوع/أدعية) لا مولّدات آلية بلا مراجعة.
7. **لا استنساخ**: أي فكرة نأخذها تُعاد صياغتها بواجهة وتجربة مختلفتين ونضيف لها قيمة.

# الأسبوع 1 — لمسات الهوية والواجهة (⭐⭐) — نبدأ اليوم

**الهدف**: تحسينات مرئية سهلة سريعة تُحسّن الانطباع الأول وتُظهر شخصية الموقع.

**1. صقل الواجهة العامة** ⭐ — مراجعة الهيدر والأزرار والتباعد والظلال والانتقالات واتساق الألوان بين السمتين؛ توحيد حلقات التركيز.
*المخرج*: واجهة أكثر رقيًّا بلا تغيير معماري. *القبول*: لقطات قبل/بعد + 0 أخطاء كونسول + فحص الجوال.

**2. بطاقة «تدبُّر اليوم» (آية اليوم)** ⭐⭐ — تصميمنا الخاص: آية مختارة يوميًا من قائمة منسّقة + زر استماع ونسخ ومشاركة وفتح في المصحف، بخلفية زخرفية خفيفة.
*المخرج*: مكوّن في الصفحة الرئيسية. *القبول*: تتغير تلقائيًا حسب التاريخ + أزرارها تعمل + تعمل بالسمتين والجوال.

**3. بطاقة «تابع القراءة»** ⭐⭐ — أعلى فهرس السور: آخر سورة/آية محفوظة + شريط تقدم + زر متابعة، وحالة بداية للزائر الجديد.
*المخرج*: مكوّن مرتبط بحفظ تقدم القراءة. *القبول*: تظهر بعد القراءة وتختفي قبلها وتفتح الموضع الصحيح.

**4. تحسين حالات الفراغ والرسائل** ⭐⭐ — صفحات العلامات/البحث/الأخطاء بحالة فراغ مصممة برسالة مفيدة وCTA.
*المخرج*: تحسين UX. *القبول*: كل حالة فراغ تعرض زرًا فعّالًا.

**5. زر تثبيت التطبيق (PWA)** ⭐⭐ — التقاط `beforeinstallprompt` وإظهار زر أنيق «ثبّت التطبيق» مرة واحدة مع إمكانية الإغلاق.
*المخرج*: تثبيت فعلي. *القبول*: يظهر عند توفر الشرط ويختفي بعد التثبيت/الرفض.

**6. لمسة زخرفية إسلامية للهوية** ⭐⭐ — نمط SVG خفيف (زخرفة هندسية) في الهيدر/بطاقات اليوم/صفحة الخطأ، بألوان السمة.
*المخرج*: أصول SVG داخلية. *القبول*: لا تؤثر على الأداء/التباين، وتعطّل تلقائيًا في وضع تقليل الحركة إن استُخدمت حركة.

# الأسبوع 2 — مكاسب SEO السريعة (⭐⭐)

**7. خريطة slugs للسور** ⭐⭐ — ملف بيانات `surahs-slugs.json`: `{id, slugEn, slugAr, aliases}` لكل 114 سورة.
**8. صور OG لكل سورة** ⭐⭐ — 114 صورة 1200×630 بأسماء وصفية + `alt` + `ImageObject` (احترام حد 20k ملف على Cloudflare).
**9. عناوين وأوصاف فريدة** ⭐⭐ — تدقيق `title/description` لكل سورة وآية وصفحة هبوط لاحقًا.
**10. دعم `?startingVerse=`** ⭐⭐ — باراميتر للانتقال لآية معينة عند فتح السورة + زر «نسخ رابط الآية».
**11. مشاركة سريعة** ⭐⭐ — واتساب/نسخ/تلغرام/X مع نص إسناد منسّق (بلا حسابات).
**12. الخرائط وrobots وGSC** ⭐⭐ — تحديث `sitemaps/*` وإرسال الخرائط في Google Search Console (يدوي بحساب المالك).

# الأسبوع 3 — الروابط الدلالية والاكتشاف (⭐⭐–⭐⭐⭐)
