# مجتمع quran.com.ly — خطة التشغيل

## 1) داخل GitHub (جاهز الآن)
- **نقاشات (Discussions)**: يجب تفعيلها يدويًا من صاحب المستودع: `Settings → General → Features → Discussions` ثم اختيار الفئات:
  - 📣 إعلانات، 💡 أفكار، 🐞 أخطاء، ❓ أسئلة، 🧩 مساهمات، 📖 تصحيحات نصية.
- **قوالب Issues**: جاهزة في `.github/ISSUE_TEMPLATE/` (بلاغ خطأ + تصحيح نص).
- **قوالب Pull Request**: جاهزة في `.github/pull_request_template.md`.
- **CI**: `.github/workflows/ci.yml` يشغّل الفحص والبناء على كل PR.

## 2) قواعد المجتمع
- احترام الجميع، وعدم فتح جدالات مذهبية أو سياسية.
- أي تصحيح شرعي/نصي يُرفق بمصدر معتمد.
- لا روابط إعلانية أو سبام.

## 3) التوسع لاحقًا
- قناة Telegram/WhatsApp للإعلانات وآية اليوم، ورابطها في قائمة ⋯.
- زر «أرسل اقتراحًا/بلّغ عن خطأ» في الموقع يفتح Issue مُعبّأ.
- التعليقات داخل الموقع تحتاج حسابات (Supabase) + إشراف — مرحلة لاحقة.
