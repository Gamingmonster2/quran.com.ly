# تراخيص البيانات والمحتوى في quran.com.ly

> شيفرة الموقع بترخيص MIT، لكن **البيانات والمحتوى الثالث** لها تراخيص مستقلة. هذه الوثيقة تلخّصها وتوضح ما يجوز وما لا يجوز.

## جدول سريع
| المحتوى | المصدر الحالي | الترخيص/القيود | الإسناد المطلوب |
|---|---|---|---|
| نص القرآن (الرسم العثماني) | quran-json | CC BY 4.0 (إسناد) | نعم — ذكر quran-json |
| الترجمة الإنجليزية (Saheeh International) | Quran.com API | وفق شروط Quran.com؛ الإسناد مطلوب | نعم — Quran.com |
| التفسير الميسر | QF API / مجمع الملك فهد | يُنصح بمراجعة شروط الناشر قبل الاستخدام التجاري | نعم |
| كلمة بكلمة (معنى/نقل صوتي) | Quran.com API | وفق شروط Quran.com | نعم |
| التلاوات الصوتية | islamic.network CDN | مجانية للاستخدام مع الإسناد، ويُمنع الإغراق؛ يُتحقق من الشروط قبل الاستخدام التجاري | نعم — islamic.network |
| الخطوط (KFGQPC, Amiri, Plus Jakarta Sans) | مصادر رسمية | KFGQPC وفق شروط المجمع؛ Amiri/Plus Jakarta: OFL 1.1 | نعم للـOFL |

## قواعد عملية
1. لا نبيع البيانات ولا نعيد ترخيصها كملك لنا؛ نوزّعها من مصادرها مع الإسناد.
2. أي تعديل على النص القرآني أو الترجمة يحتاج مراجعة بشرية ومصدرًا موثوقًا (انظر قالب «تصحيح نص»).
3. نذكر المصادر في صفحة `/sources` وفي هذا الملف، ونحدّثها عند إضافة مصدر جديد.
4. قبل أي استخدام تجاري للتلاوات/التفسير: راجع شروط المصدر مباشرة.
