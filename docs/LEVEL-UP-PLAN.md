# خطة الوصول إلى مستوى quran.com — تحليل وفجوات وخطوات تنفيذية

> وثيقة عمل داخلية لمشروع quran.com.ly. أُعدّت بعد فحص مباشر للموقع المرجعي (quran.com) ومقارنته بحالة موقعنا الحالية.
> الهدف: **منافسة الكلمات المفتاحية الطويلة** أولًا، ثم الاقتراب تدريجيًا من تجربة quran.com الكاملة — دون نسخ تصميمهم أو محتواهم.

---

## 1) ملخص تنفيذي

- quran.com ليس موقعًا واحدًا بل **منظومة** تديرها مؤسسة غير ربحية (Quran Foundation): واجهة أمامية تقنية Next.js + API خاص + تطبيقات iOS/Android + مشاريع شقيقة (QuranReflect للتدبر، Quran Space للتعلم، Quran.ai، Quran Audio، Sunnah.com، Corpus.Quran.com).
- المنافسة المباشرة على الكلمات القصيرة («القرآن الكريم»، «quran») **غير واقعية** في المدى القريب. المنافسة على **الكلمات الطويلة وصفحات الهبوط** (اسم السورة + ميزة محددة، آية الكرسي، يس، الملك، آية اليوم، التفسير لسورة معينة…) **واقعية جدًا** ولدينا أفضلية تقنية (سرعة، صفحات ثابتة، PWA، مجانية كاملة).
- موقعنا الحالي يمتلك أساسًا قويًا: 114 صفحة سورة + 6236 صفحة آية مُصيَّرة مسبقًا، ترجمة/تفسير/كلمة-بكلمة، 15 قارئًا، بحث عربي مطبَّع، عربي/إنجليزي، PWA أوفلاين، API ثابت، SEO/hreflang/sitemaps.
- الفجوات الكبرى مقابل quran.com: **الروابط بالأسماء (slugs)**، صفحات الهبوط المخصوصة، آية اليوم/الأسبوع، المشاركة/بطاقات الآيات/embeds، التجويد الملوّن، وضع المصحف بالصفحات، تعدد اللغات/الترجمات/التفاسير، الحسابات والمزامنة، المحتوى التعليمي، وأدوات إنشاء الوسائط.
- التقدير: **للمنافسة في الكلمات الطويلة: 8–10 مهام (2–4 أسابيع عمل متقطّع)**. للاقتراب الملموس من تجربة quran.com: **~30 مهمة (2–4 أشهر)**. التكافؤ الكامل = فريق + بنية خلفية + سنوات.

**استنتاج**: نقاط قوتهم = المحتوى الضخم + اللغات + الحسابات + الأدوات (تجويد/وسائط) + العلامة التجارية.

## 4) استراتيجية الكلمات المفتاحية (الجواب المباشر على سؤالك)

1. **الكلمة القصيرة** «القرآن الكريم»: لا نطاردها الآن؛ المنافسة عليها بين مواقع ضخمة (quran.com، إسلام ويب، الأزهر…). تُبقى في هوية الموقع وعنوانه للثقة والعلامة.
2. **المنافسة الحقيقية = Long-tail**، ولدينا بنية جاهزة: 114 سورة + 6236 آية + ترجمة + تفسير + كلمة-بكلمة.
   - أمثلة: «سورة المجادلة مكتوبة بالتشكيل»، «الآية 2 من سورة المجادلة مع الترجمة»، «تفسير سورة الكهف»، «آية الكرسي مكتوبة»، «يس بدون نت»، «معاني كلمات سورة الملك»، «استماع سورة الواقعة مشاري العفاسي».
3. **الروابط بالأسماء (slug)**: نعم ننتقل إليها، لكن مع توضيح: كلمات URL عامل ترتيب **ضعيف** مقارنة بالعنوان والمحتوى والروابط الداخلية؛ قيمتها الحقيقية في:
   - وضوح الرابط ومناسبته للكتابة/النسخ (عربي/إنجليزي)،
   - دعم CTR والمشاركة،
   - بناء صفحات هبوط لكل سورة باسمها.
   - **الأهم**: `title`/`H1`/المحتوى/الوصف، وروابط داخلية بمئات الروابط بين السور والآيات والتفاسير.
4. **صفحات الهبوط المخصوصة** هي أسرع مكسب: تكرر نموذج quran.com (`ayatul-kursi`, `ya-sin`, `al-mulk`, `ar-rahman`, `al-waqiah`, `al-kahf`, `al-muzzammil`) بصفحة عربية **باسم الكلمة المفتاحية في المسار والعنوان**، وبمحتوى آية/سورة + تفسير + تلاوة + مشاركة + أسئلة شائعة.
5. **اللغات مصدر كلمات مفتاحية هائل**: كل لغة واجهة + ترجمة = سطح كلمات جديد (quran.com يفرد `sitemap-translations`). نبدأ بأهم 5–10 لغات.
6. **الصور وSEO**: تسمية الصور/OG بأسماء وصفية (`al-mujadila-ayah-2-tajweed.png`)، `alt` عربي/إنجليزي، و`ImageObject` في JSON-LD.

## 5) النقاط المطلوبة (خطة مراحل)

### المرحلة A — SEO سريع (أسبوع 1–2) — أولوية قصوى
1. **Slugs للسور**: خريطة 114 اسمًا (عربي + transliteration kebab-case) وراوتر يدعم `/{locale}/{slug}` و`/{locale}/{slug}/{ayah}` مع `?startingVerse=N`.
2. **Canonical**: تحويل الروابط القديمة الرقمية إلى بدائل (بقاءها تعمل مع `canonical` للـslug، أو 301 إن أمكن عبر Cloudflare Functions).
3. **إعادة توليد prerender/sitemaps/hreflang** على slugs + إضافة `sitemap-translations` مستقبلًا.
4. **صور OG لكل سورة/آية** (1200×630) باسم وصفي + `ImageObject` + `alt`.
5. **صفحات هبوط مخصوصة** لأشهر الكلمات: آية الكرسي، يس، الملك، الرحمن، الواقعة، الكهف، المزمل، الفاتحة، الناس، الإخلاص + «آية اليوم».
6. **روابط داخلية**: «الآية السابقة/التالية»، «السورة التالية»، أقسام «آيات مشابهة/مواضيع السورة».
7. **بيانات منظّمة إضافية**: `AudioObject` للتلاوات، `Quotation` للمشاركات، `FAQPage` لصفحات الهبوط.
8. **إحصاءات GSC** ثم ضبط العناوين على بيانات حقيقية.

### المرحلة B — المشاركة والوسائط (أسبوع 3–5) — تميّزنا المجاني
9. **بطاقة آية PNG** في المتصفح (نص + ترجمة + رقم + علامة مائية quran.com.ly + خطوطنا المحلية) وتحميلها.
10. **أزرار مشاركة**: واتساب، X، فيسبوك، تلغرام، نسخ رابط/نص مع الإسناد.
11. **Embed**: مسار `/embed/{locale}/{slug}/{ayah}` بتصميم مصغّر + كود `<iframe>` جاهز + توثيق.
12. **فيديو آية في المتصفح** (Canvas + تلاوة + علامة مائية + MediaRecorder) — بديل مجاني/بلا سيرفر لأداة quran.com المحدودة بالرصيد؛ يتطلب فحص CORS للصوت.
13. **آية اليوم/الأسبوع** (تدوير من قائمة منسّقة) + صفحات `/daily`، `/verse-of-the-week`.
14. **ملاحظات/تدبرات شخصية محلية** + مشاركة كصورة.

### المرحلة C — تجربة القراءة (أسبوع 5–9)
15. **وضع التجويد الملوّن**: جلب بيانات «Uthmani Tajweed» للآيات عند البناء (6236 آية) وتلوين القواعد مع مفتاح ألوان وتعريفاتها ووضع إخفاء/تبديل.
16. **وضع المصحف بالصفحات**: خطوط QCF لصفحات 1–604 مع تنقّل صفحة/مربع/جزء (خطوط ثقيلة، تُحمّل عند الطلب).
17. **تعدد التفاسير**: الميسر + ابن كثير + السعدي + الطبري (بحسب التراخيص) مع مفاتيح.
18. **تعدد الترجمات**: إنجليزية + أهم 5–10 لغات + تبديل، مع «الترجمة الحرفية/بالعربي» في القارئ.
19. **الترجمة الصوتية (Transliteration)** للقراءة لغير الناطقين.
20. **تظليل الكلمة أثناء التلاوة** (Word-by-word audio sync) إن توفرت بيانات التوقيت.
21. **صفحات معلومات السورة** `/surah/{slug}/info` (مقدمة تفسيرية، فضائل، أسباب النزول حيث توجد مصادر حرة).
22. **اختيار القارئ الموسّع** (رفع العدد من 15 إلى 30+ إن توفرت روابط)، واختيار جودة الصوت.

### المرحلة D — المحتوى والتعلّم (أسبوع 9–14)
23. **فهرس المواضيع** `/explore` (تصنيف آيات/سور بمواضيع: الصبر، الرحمة، الصلاة…) مبني من كلمات مفتاحية/وسوم.
24. **القرآن في عام** `/calendar` (خطة رمضان→رمضان).
25. **هدف القراءة والإحصاءات** (محلي أولًا، ثم مزامنة عند إضافة الحسابات).
26. **صفحات أدعية من القرآن** `/duas`.
27. **قسم تطبيقات/مطورون**: `/developers` لتوثيق API (لدينا `/api` و`docs/API.md` — نوسّعه).
28. **مدونة/تحديثات المنتج** لالتقاط كلمات مفتاحية إخبارية.

### المرحلة E — الحسابات والبنية الخلفية (أسبوع 14–20) — تغيير معماري
29. **تسجيل دخول Google** عبر مزوّد مجاني (Supabase/Firebase) — لموقع ثابت.
30. **مزامنة**: العلامات، تقدم القراءة، الملاحظات، الأهداف عبر الأجهزة.
31. **تعليقات/تدبرات عامة** (اختياري ومُدار) — عبء إشراف؛ البديل: صفحات تدبر منسّقة.
32. **تحليلات مرنة + مراقبة أخطاء + مراجعة أداء/إتاحة**.

### المرحلة F — التوسع (مستمر)
33. لغات واجهة إضافية (10–20) + hreflang + خرائط مترجمة.
34. تفاسير/ترجمات أوسع + خطوط مصحف + قراءات (حفص/ورش…).
35. تطبيقات PWA محسّنة (تثبيت، مشاركة أصلية) وربما تطبيق جوال لاحقًا.

## 7) أول 5 خطوات نبدأ بها فورًا (الأسبوع الأول)

1. **Slug URLs** + canonical + startingVerse (بدون كسر الروابط الحالية).
2. **OG images لكل سورة/آية** بأسماء وصفية + JSON-LD للصور.
3. **صفحات هبوط**: آية الكرسي، يس، الملك، الرحمن، الواقعة، الكهف.
4. **آية اليوم/الأسبوع**.
5. **بطاقات المشاركة PNG + أزرار واتساب/مشاركة** وembed أساسي.

## 8) قرارات وأسئلة مفتوحة

- **اسم الموقع الشرعي الجديد** (يُقرَّر من المالك) — يؤثر على العلامة والـTitle/Logo.
- هل نركّز عربي أولًا أم عربي+إنجليزي معًا؟
- بيانات التجويد/التفاسير الإضافية: تحقّق تراخيصها قبل الإدراج.
- الحسابات: هل نضيف Supabase (مجاني) أم نُبقي الموقع محليًا بالكامل؟
- الفيديو: نبدأ ببطاقة PNG ثم فيديو في المتصفح بعد فحص CORS للصوت من CDN.
- ملاحظة: المُستخدم ذكر وجود «خطأ إملائي» في صفحة — يلزم تحديد موضعه لإصلاحه.
